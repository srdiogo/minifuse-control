MiniFuse Control includes the desktop mixer, session backend, DKMS driver and
optional desktop activation agent. Ubuntu 26.04 LTS uses the DEB, Fedora 45 uses
the RPM, and Arch Linux uses the complete archive of native packages.

MiniFuse 4 has physical validation. MiniFuse 1, 2 and 2 OTG controls remain
experimental and appear automatically when firmware, driver and readback
checks pass.

See the [installation guide](https://github.com/srdiogo/minifuse-control/blob/main/docs/NATIVE_PACKAGES.md)
and the separately distributed [Omarchy panel](https://github.com/srdiogo/omarchy-minifuse/releases).
